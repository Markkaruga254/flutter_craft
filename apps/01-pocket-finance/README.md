# Pocket Finance

**Week 1 · Finance dashboard**

Build a polished personal finance dashboard that makes a user's money activity easy to scan.

## Planned features

- Overview of a fictional account balance
- Income and expense summaries
- Recent transaction history and categories
- Clear visual hierarchy and responsive layout
- Navigation between the main sections

## Build sequence

Start with static mock data and the simplest widgets that solve the layout. Add interactions and data entry only when the core dashboard is stable. Later iterations can introduce local persistence, authentication concepts and API integration.

## Safety

This is a learning project. Use mock data only. Do not use real banking credentials, connect real accounts or implement real-money transactions.

## Run

Once the Flutter app has been scaffolded in this directory:

```bash
flutter pub get
flutter run
```
