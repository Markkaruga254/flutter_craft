# Week 2 — TasteMap

**Theme:** image-rich discovery, scrolling, search, filtering and navigation.

Build a food and place discovery experience using a small, fictional/local sample dataset. Learn to make long content browsable and help users move from discovery to detail.

Suggested progression: asset and image handling; list/grid composition; reusable place cards; search input; category filters; navigation and detail pages; polish, accessibility and tests.

The daily challenge brief provides the exact task and acceptance criteria for each day.
