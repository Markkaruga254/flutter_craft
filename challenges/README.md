# Daily coding challenges

The programme runs for 56 days: one practical task per day, grouped into eight weekly app projects.

Each challenge should be attempted before looking for a full solution. The daily challenge delivery provides the next task in sequence; this directory is the durable repository record and index.

## How to submit your work for review

Share the day number, a short explanation of your implementation, relevant code, a screenshot or screen recording where useful, and test/analyzer output. If blocked, include the exact error and what you tried.

Missing a day is not a reason to skip ahead. Resume at the next unfinished challenge.
