# Daily coding challenges

The complete 56-day programme is now recorded in this directory: **one individual Markdown brief per day**, grouped into eight weekly app projects. Each daily file contains a user story, implementation task, requirements, acceptance checklist, stretch goal, verification steps, reflection prompts and submission guidance.

## How to submit your work for review

Share the day number, a short explanation of your implementation, relevant code, a screenshot or screen recording where useful, and test/analyzer output. If blocked, include the exact error and what you tried.

Attempt the task before looking for a full solution. Missing a day is not a reason to skip ahead: resume at the next unfinished challenge.
