# Day 25 — Forma product catalogue

**Week 5 · Connect**

## User story

As a user, I want to forma product catalogue so that the app feels useful, clear and reliable.

## Your task

Create a product model and catalogue screen with image, name, price and category. Use fictional products and reusable product cards.

Start by running the current app and inspecting the relevant widgets. Implement the smallest complete version of this feature. Use typed Dart, keep widget responsibilities clear, and avoid adding dependencies unless you can explain why they are needed.

## Requirements

- Keep the work focused on this feature; do not build unrelated screens.
- Handle the main interaction and at least one edge case.
- Use meaningful labels and sensible touch targets.
- Keep sample data fictional. This is a learning/demo application, not a production service.

## Acceptance criteria

- [ ] Catalogue is data-driven
- [ ] Price formatting is consistent
- [ ] Cards have stable keys
- [ ] Image fallback exists.
- [ ] The app runs on the configured Android device or emulator.
- [ ] Dart formatting and flutter analyze have been run; no new analyzer issues are introduced.

## Stretch goal

Add a featured product section.

## Verification

1. Run dart format on the app.
2. Run flutter analyze.
3. Run flutter test and add a focused test for testable logic or interactions.
4. Manually test the main path and the relevant edge case.
5. Capture a screenshot or short recording if the result is visual.
