# Week 1 — Pocket Finance

**Theme:** Dart and Flutter foundations, widget composition, layout constraints and responsive UI.

**Product brief:** Build a personal finance dashboard using clearly labelled mock data. It should help a user understand their balance, recent activity and spending at a glance.

## Seven-day sequence

1. **Day 1 — Environment and first app:** verify Flutter, create/run the app, understand `main()`, `runApp()` and the widget tree; complete a small Dart exercise.
2. **Day 2 — Dart essentials:** variables, types, collections, functions, null safety and simple model data.
3. **Day 3 — Widget composition:** build a clear app shell and reusable UI sections; understand StatelessWidget and build().
4. **Day 4 — Layout constraints:** use Row, Column, Expanded, Flexible, Padding, SizedBox and scrolling deliberately; diagnose overflow.
5. **Day 5 — Finance dashboard:** compose balance, income/expense summaries and transaction rows from mock data.
6. **Day 6 — Responsive polish:** adapt spacing and composition to different widths; add empty states and accessible labels.
7. **Day 7 — Review and test:** refactor carefully, add useful widget tests, run analysis and document the app.

The daily task delivered to you is the precise source of truth for that day's requirements and acceptance criteria. This list is the weekly overview, not a substitute for the daily brief.

## Pocket Finance boundaries

- Use fictional data and names.
- No real bank credentials, account connections, payments or transfers.
- Keep the first iteration simple; add persistence and backend integration in later stages when the fundamentals are understood.
